# Level 5 — The SLP Framework

## What this level covers
Your first real introduction to SLP — Structured Liquidity & POI. This level covers
what a valid Point of Interest (POI) is, how to confirm it, and how to mark it correctly.

## What SLP stands for
SLP = Structured Liquidity & POI. The strategy is built around finding a specific
Point of Interest (POI) on the chart — the exact zone where price is likely to
react — and confirming that zone using structure, liquidity behavior, and price
action before ever entering a trade. It is fundamentally about patience: waiting
for the market to prove a zone matters, instead of guessing at a level and hoping
it holds.

## The POI: Order Blocks
The core POI in SLP is the order block — the last bullish or bearish candle before
a move that breaks structure. This is non-negotiable: the move away from the
candle MUST break structure (a Break of Structure, or BOS) for that candle to
qualify as a valid order block. If structure isn't broken, it is not a valid POI —
no exceptions.

## Confirmation: The Fair Value Gap (FVG)
Once a valid order block is identified, check whether the move that caused the BOS
left behind a Fair Value Gap (FVG) — a gap in price where no trading occurred,
sitting between candles. If the impulsive move has an FVG in it, the setup's
probability rises significantly — roughly to 70% based on real trading experience.
This is a strong confirmation signal, but it is NOT a guarantee. A setup without an
FVG can still work; a setup with one is simply statistically stronger.

## How to mark an order block correctly
Precision matters — the exact boundaries of the order block determine where price
is expected to react:
- If the body of the order block candle is longer than its wick(s) -> mark the
  ENTIRE candle (body and wick together).
- If the wick is longer than the body -> mark ONLY the candle body, leaving the
  long wick out of the zone.

## Common mistakes at this level
- Marking a candle as an order block when the move away from it never actually
  broke structure.
- Treating an FVG as required rather than a probability booster - a valid setup
  without one is still tradeable.
- Marking the whole candle (including a long wick) when the wick-longer-than-body
  rule says to mark only the body, making the zone too wide and imprecise.

## What a student must demonstrate to pass this level
Given a chart, correctly identify a valid order block (confirming the BOS that
follows it), check whether an FVG is present in that move, and mark the zone using
the correct body-vs-wick rule.
